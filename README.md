# 알잘딱

운전석과 동승석의 공조 조작을 기록해 이름 있는 프로필로 저장하고, 시동 시간이나 실내 온도에 따라 열선 루틴을 실행하는 Android 프로토타입입니다.

## 실행 방법과 테스트 환경

Pleos Connect v2.1.0 에뮬레이터(Android API 34, 가로 2560 × 1440 px, 160 dpi)를 실행하고, 아래 릴리스 APK를 설치한 뒤 앱 목록에서 **알잘딱**을 엽니다.

소스로 실행하려면 Android Studio에서 저장소 루트를 열고 Gradle JDK를 17로 설정합니다. Android SDK Platform 35를 설치하고 Gradle Sync를 실행한 뒤 Pleos AVD에서 `app` 실행 구성을 선택합니다. 최초 동기화에는 인터넷 연결이 필요합니다. Windows 디버그 빌드는 `.\gradlew.bat :app:assembleDebug` 명령을 사용합니다.

## 시연 순서

1. **트래킹**에서 이름과 기간을 정해 기록을 시작합니다. **홈**에서 두 좌석의 설정 온도, 풍량, 풍향, 열선 또는 통풍을 조작합니다.
2. 기록을 종료하고 **공조 프로필**에서 저장된 프로필을 켭니다. 홈에서 모의 시동을 켜면 가까운 조건의 학습값이 적용됩니다. 자동 조절 중 직접 바꾼 항목은 해당 세션에서 수동값을 유지하고, 프로필이 적용한 값과의 차이를 다음 학습에 반영합니다.
3. **루틴**에서 시동 경과 시간 또는 실내 온도 템플릿을 선택하고 좌석과 숫자 조건을 지정한 뒤 켭니다. 같은 좌석의 열선은 루틴이 프로필보다 우선합니다. 프로필은 한 번에 하나, 루틴은 좌석당 하나를 켤 수 있습니다.
4. **데이터**에서 실행 및 조작 기록을 확인합니다. 조작 기록 삭제는 진행 중인 트래킹도 지우며, 저장된 프로필은 프로필 화면에서 별도로 삭제합니다.

학습은 실내 온도, 하루 안의 시각, 시트 통풍 및 열선 단계의 거리를 사용합니다. 데이터는 기기 내부에 저장됩니다. 자동 적용 시 설정 온도는 0.5°C씩 이동하고, 열선에는 30분 연속 가동 상한이 있습니다. 학습으로 가동된 열선이 계속 필요한 경우에는 10분 가동 후 5분 쉬는 기본 주기를 사용합니다.

홈의 조작과 시동·실내 조건은 앱 내부 모의 값입니다. 실제 Pleos Vehicle SDK 구독과 공조 명령, Virtual Console 연결, 주행 규제 판정 및 백그라운드 실행은 미연동입니다. 음성 안내는 기기에 설치된 한국어 오프라인 Android TTS 음성이 있을 때 켤 수 있습니다.
